# Vocal stems, XDJ-AZ firmware 1.30

Sidecars are still made on the computer (Vocal Stems tab) as `.rx3stem`
files in `AZ_STEMS/` on the stick. On-device mixing needs a performance
core hooked into `rbp`, and that core is not mapped for 1.30.

This module only publishes the folder. Audio and pads stay stock.
