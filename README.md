<h1 align="center">
  XDJ-AZ Toolkit
</h1>

<p align="center">
  A fail-closed port of <a href="https://github.com/Tratosca/rx3-toolkit">Tratosca’s XDJ-RX3 Toolkit</a> to the XDJ-AZ.
</p>

> **Hardware probe result (1.30, 2026-08-29):** the AZ does not run `autoexec.bin`, and its only open network port is the documented PRO DJ LINK metadata channel. There is currently **no software path** that lets this toolkit execute on the player. The runtime stays fail-closed and ready in case a future firmware exposes one. Full write-up: [docs/az-hardware-probe.md](docs/az-hardware-probe.md).
